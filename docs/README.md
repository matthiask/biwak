# Help

Biwak is where a team keeps its projects together with its clients:
to-do lists, messages, docs and files, and check-ins, with an activity
feed and mails about what happens. Clients see only what staff show
them. This help explains how to use it, short and in the order you need
it.

- [Finding your way](orientation.md): Home, projects, to-dos, activity,
  the lantern, bookmarks, search, people, teams
- [To-dos](todos.md): lists, groups, assigning, due dates, repeating,
  checklists, the to-dos page, the calendar
- [Messages, docs and files](files.md): the message board, folders,
  docs written together, versions, uploads, attachments
- [Check-ins](checkins.md): questions asked on a schedule
- [Notifications](notifications.md): the lantern, mails, digests,
  levels, replying by mail, forwarding mails to file them
- [Clients](clients.md): what clients see, showing and hiding, what
  they can do
- [Keyboard](keyboard.md): the command palette and the shortcuts
- [Signing in](sign-in.md): codes, passkeys, an authenticator app as
  a second step, resets, single sign-on with Google or Microsoft,
  setting it up
- [The CLI and the API](cli.md): tokens, the `biwak` command
- [Coming from Basecamp](basecamp.md): what's different and why, what
  Biwak doesn't do
