# Biwak

A small, self-hosted project management tool for teams working with
clients: projects, to-do lists, message boards, docs and files, check-ins,
an activity feed, and access for clients to exactly what they should see.
Basecamp's focus on the essentials, without Basecamp.

A bivouac is the minimal camp: only what you need to get up the mountain.

**Status:** specification only, nothing built yet.

- [`SPEC.md`](SPEC.md): what the app does and why, the model, the
  decisions, the build order
- [`specs/`](specs/): one spec per part of the app, each small enough to
  hand to one agent
- [`AGENTS.md`](AGENTS.md): conventions for working on the code
